# SmartStart SaaS

Production-style React + TypeScript demo application for generating and managing landing page projects.

## Stack

- React
- TypeScript
- Vite
- SCSS
- React Router
- React Hook Form
- Zod
- Zustand
- TanStack Query
- Axios

## Features

- Authentication flow
- Protected routes
- Dashboard
- Project generator
- Project preview
- Template gallery
- API service layer
- Query caching
- Error states
- Lazy loaded routes

## Notes

This is a portfolio/demo project. It uses mock authentication and JSONPlaceholder-style API data.
